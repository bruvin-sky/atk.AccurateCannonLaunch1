# Accurate Cannon Launch

A mod that tweaks the Probe Tracking Module to break off from the Orbital Probe Cannon, and fall into Giant's Deep at the start of each loop.

To give you a better view without use of freecam mods, this mod adds a projection pool at the launch tower, that will automatically pair you to the pool aboard the falling module. (This addition can be disabled in the mod's options - it is enabled by default!)

Note: for inscrutable reasons, the projection pool will only automatically pair on the first loop of a session, so you will have to manually reset the projection stone on any subsequent loops. BlehCat
