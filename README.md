# Accurate Cannon Launch

A mod that tweaks the Probe Tracking Module to break off from the Orbital Probe Cannon, and fall into Giant's Deep at the start of each loop.

<img width="1920" height="1080" alt="Screenshot 2026-05-07 164835" src="https://github.com/user-attachments/assets/142afdf9-3606-4f69-a9ae-ae51d03cc64a" />

To give you a better view without use of freecam mods, this mod also adds a projection pool at the launch tower, which will automatically pair you to the pool aboard the falling module! (This addition can be disabled in the mod's options, and is enabled by default)

NOTE: The added projection pool will only automatically pair after the wake-up prompt. The projection stone will have to be manually reset on any subsequent loops, unless you quit to title. Sorry bout that *blehCat*

I recommend just watching the projection pool on your first loop, then enjoying an exterior view using the signalscope afterwards!
